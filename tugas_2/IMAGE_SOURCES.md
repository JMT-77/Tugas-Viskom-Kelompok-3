# Sumber gambar internet untuk uji coba Tugas 2

Gambar berikut diunduh dari Wikimedia Commons melalui endpoint `Special:FilePath` dan dikonversi ke PNG untuk digunakan sebagai input OpenCV.

| File input | Sumber unduhan | Penggunaan |
|---|---|---|
| `tugas_2/data/input/internet_apple.png` | https://commons.wikimedia.org/wiki/Special:FilePath/Apple.jpg?width=330 | Pencerminan dan noise reduction |
| `tugas_2/data/input/internet_peppers.png` | https://commons.wikimedia.org/wiki/Special:FilePath/Peppers.jpg?width=330 | Rotasi |
| `tugas_2/data/input/internet_landscape.png` | https://commons.wikimedia.org/wiki/Special:FilePath/Landscape.jpg?width=330 | Deteksi tepi |

Gambar disimpan dalam ukuran kecil agar mudah dipakai untuk pengujian. Sumber dan status lisensi tetap perlu diperiksa pada halaman Wikimedia Commons sebelum gambar dibagikan di luar repository atau digunakan dalam publikasi.
